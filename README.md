# Nexus

A website for a software company, with a work gallery, a live quote builder and contact forms, plus an admin panel and a customer portal.

**Live:** []

## Features
- Work gallery managed from an admin panel
- Quote builder that updates the price as you pick features and a timeline
- Contact and quote forms that save leads for the admin to review
- Admin panel: projects, leads, customers and contact details
- Customer portal where clients see their website's visit stats

## Built with
HTML, CSS and vanilla JavaScript on the front end. Supabase for the database, sign-in and storage, with Row Level Security on every table.# nexus-portals
